# 牛来建模参考 v01

2026-10-18，Codex。按沟通板最新的 3D 路线生成，供用户拿去混元建模。**这是建模参考候选，不是模型、贴图或已入库游戏精灵。**

| 文件 | 用途 |
| --- | --- |
| `niulai_front_apose_v01.png` | 主参考，正面全身、A 字姿势、空手 |
| `niulai_side_apose_v01.png` | 补充参考，纯侧面朝右；侧投影下左右肢体自然重合 |
| `prompts_v01.md` | 全部实际提示词、引用图片、4 次抽卡记录 |
| `verification_v01.json` | PNG 解码、尺寸、不透明度、轮廓边界、SHA256 和检查限制 |
| `attempts/` | 未选用的两张初稿，保留追溯 |

采用内置 `image_gen`，正面 2 次、侧面 2 次，合计 **4 次**。输入为 `../../reference/poses/niulai_hd_idle.png` 和 `niulai_idle_tail_x4.png`；侧面另参考本轮正面图。没有改动旧基准。

两张均为 1254×1254 RGB PNG、全不透明，角色约占高度 85.7%，脚底相差 2px。已目视检查无角、奶油鼻头、一条粗眉、粉耳内侧、圆肚子、棕短裤/腰带/蹄子、短尾深色尾尖；没有拿剑，没有明显落地投影。

限制：这是分别生成的两个 2D 视图，**不是同一网格的精确正交投影**，头/腰线仍可能有小幅差异，建模以正面比例为主。颜色仍有轻微渐变、白底角落实测 RGB 253–255，没有声称逐像素纯白或完全无渐变；这些图不用于直接烘焙游戏光照。若混元只能用一张图，优先正面；若可用多视图，再加侧面，不用把两张图拼成单张输入。

下一步由用户操作混元，导出 GLB 或 FBX，放入 `../model/`。模型拿到之后再检查网格、材质、骨骼，决定绑骨/重定向。剑在 Blender 单独制作。现在尚未进行绑骨、套 UAL2、渲染或像素化，也没有运行 Godot。
