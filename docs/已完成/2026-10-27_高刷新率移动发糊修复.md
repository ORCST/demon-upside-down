# 2026-10-27：高刷新率显示器上移动发糊修复（Devin）

用户反馈：“运动起来似乎有点模糊感”。

## 原因

用户显示器是 144Hz（RTX 5070，2560×1440），游戏物理是 60Hz，而且没有开物理插值：
- 角色位置每秒只更新 60 次，画面每秒刷新 144 次，所以角色会“停两三帧、跳一格”。
- 相机原来在渲染帧里平滑跟随，和角色不同步，两者的相对位置一直在抖。
- 像素画边缘锐利，这种抖动看起来就像发糊、拖影。

不能把物理改成 144Hz：所有招式帧数都按 60fps 写的。

## 改动

| 文件 | 内容 |
| --- | --- |
| `project.godot` | `[physics] common/physics_interpolation=true`，Godot 自带物理插值，物理帧之间平滑显示 |
| `scripts/world/game_camera.gd` | 跟随改在 `_physics_process`，`process_callback` 设为 PHYSICS，相机和角色一起被插值；震屏仍在 `_process` 里用真实时间计算（顿帧时照样抖） |
| `scripts/player/player.gd`、`scripts/enemies/enemy.gd` | 复活瞬移后调用 `reset_physics_interpolation()`，不会从死亡位置滑过去 |
| `scripts/autoload/juice.gd` | `spawn()` 生成特效后调用 `reset_physics_interpolation()`，特效不会从原点飞过来 |

## 验证

- 自动演示完整跑完，伤害和位置日志与修改前一致（相机坐标差 1–6px，是插值导致的正常差异）。
- 录屏模式固定 60fps，看不出 144Hz 下的改善，**需要用户在自己的显示器上实测**。

## 如果还觉得糊

- 可能是 3D 渲染帧之间的像素“闪动”：每帧独立像素化，轮廓内部的像素会跳。跑步 24fps 时最明显。可以降低跑步帧率，或者在像素化时做帧间稳定。
- 也可以对比开关垂直同步，或者把显示器临时切到 60Hz，判断是不是刷新率的问题。
