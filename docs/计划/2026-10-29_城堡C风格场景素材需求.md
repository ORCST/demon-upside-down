# 城堡场景 C 风格：拆分素材需求（给 Codex/GPT）

作者：Devin，2026-10-29。用户选定 **C 可爱卡通风格**，风格基准图是 `art_source/environment/castle_style_studies_20261029/castle_C_cartoon_v02.png`：圆角大石块、粗深色描边、大色块平涂、暖紫夜色、橙色火光、前景深色剪影。

## 为什么要拆素材

- KayKit 3D 渲染做不出这种质感（细碎小砖、没有粗描边），场景改走“GPT 按样张风格生成拆分素材 → 统一像素化 → Devin 在 Godot 里拼装”。
- 关卡要反复改布局，地面必须是能平铺的图块；背景要分层视差；火把要有动画。所以不能用一张整图。

## 统一规格（所有素材都要遵守）

- **原生像素**：游戏画面 640×360，牛来站高约 64px，地面顶沿在屏幕 y=300 附近。下面的尺寸都是原生像素尺寸。生图可以大尺寸出，但最后必须缩到这个尺寸：按面积缩小，再用最近邻对齐网格。
- **调色板**：从 `castle_C_cartoon_v02.png` 提取一套共用调色板（约 32 色，必须包含描边用的深紫黑），所有素材都吸附到这套色，**不抖动**。调色板存成 `palette_c.png`（每色 1 像素）和 `palette_c.json`。
- **描边**：可踩的地面、平台、前景物件用 1–2px 深色描边；远景墙面描边较淡或不描边，保证层次。
- **透明**：除天空层外都是透明背景，alpha 只有 0/255，不要半透明边。
- **光照**：光从左上方来；火把附近的暖光让 Devin 在游戏里叠加光晕，**素材本身不要画大片发光**。
- **平铺**：标了“平铺”的素材左右边缘必须能无缝衔接（有竖向平铺要求的，上下也要）。交付前把每张平铺素材横向拼 3 份，检查接缝。
