## 已有处理与验证

- 16 项均为指定尺寸 RGBA，alpha 仅 0/255；墙面/地面纹理区本身不透明，物件外部和窗洞透明。大/小窗分别有 7888/3517 个透明像素。
- 所有可见色属于样张提取的同一套 32 色，无抖动。提取时增加火把/木板区域权重，并保留月亮/火焰高光；`palette_c.png` 为 32×1，每色一像素。
- 首轮地面透明处理中出现暗洞/杂点，第二稿改用完整不透明纹理面再整理；顶沿第二稿的外部白底已剔除，最终地面使用修订稿。
- 缩小后先作窄带接边处理，再吸附调色板。天空、墙、地面、铁链相对边界一致；QA 图按要求重复 3 次，地面墙体为 3×3，铁链为纵向，木板只重复中段。
- 四帧火焰不同，下半部托架 `[0,24,24,48]` 完全相同；GIF 解码为 4 帧。火把和灯笼素材没有大片外部光晕。
- 已有拼装图采用指定牛来原生待机图，画布偏移 `[48,92]`，身体中心约 x160、脚底最后像素 y299；角色仍用原调色板。640×360 到 1280×720 为精确最近邻 2 倍。
- 游戏/资产/主角3D 的 2012 个原有文件 SHA256 与本轮开始一致。最新指示后仅补清单和交接，未继续生成、调整图像或制作场景。

## 限制与交接

窗框暖色亮边偏强，墙面砖纹比样张规则；旗帜尾部偏三尖，并非严格双尖燕尾。这些限制留待后续明确任务处理。接边检查和静态预览不等于实际滚动验证；视差、碰撞、光晕和游戏内可读性由 Devin 制作并实测。

已有 [处理脚本](../../../tools/build_castle_c_assets.py) 仅作复现资料，使用系统 Python 3.11、Pillow/numpy/cv2，无新增依赖。完整交接带本目录（含 raw/qa）和脚本；原始 Codex 缓存已有项目内副本。当前游戏保持原有 3D 城堡，素材候选尚未获替换批准。
