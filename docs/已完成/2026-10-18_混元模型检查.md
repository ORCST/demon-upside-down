# 2026-10-18：混元 3D 牛来模型检查（Devin）

检查对象：用户用混元生成的 `art_source/3d/reference/9a238c874d291ec59ea7b5bd02d0d64b.fbx`（26.9MB）。只做检查和渲染测试，没有改模型。

## 方法

- Blender 5.2 后台导入，读取网格、骨骼、材质和贴图信息；渲染正面、背面、左右侧面四个视图。
- 像素尺寸测试：正交侧视、面朝右，设成站高 64 原生像素、脚底 y=207。先渲染 1024 像素，再按面积缩到 256 画布，用 `prep_sprites` 的 `snap` / `denoise` / `outline` 处理。做了两版：平涂，以及 2 阶卡通阴影。
- 脚本和输出在 `outputs/fbx_inspect_devin/`（被 git 忽略）：`inspect_fbx.py`、`pixel_test.py`、`info.json`、`view_*.png`、`px_compare.png`（手绘待机 / 平涂 / 卡通对比）。

## 模型数据

- 单个网格 `node_0`：25,002 顶点、50,000 三角面，有一套 UV，单一材质。
- 4K PBR 贴图已打包进 FBX：颜色、金属度、法线、粗糙度。
- **没有骨骼，也没有顶点组**，要绑骨。
- 高约 1.078 单位，脚底在 z=0，朝向正确，双臂 A 字微张。

## 结论：可以用（需要小修＋绑骨）

外形还原度很好：圆头、粉色耳朵内侧、奶油色鼻头、粗眉毛、圆肚子、棕色短裤和腰带、蹄子、带尾尖的尾巴都有，比例是大头短身。

问题：

| 问题 | 严重程度 | 处理 |
| --- | --- | --- |
| 没有骨骼 | 必须处理 | 绑骨：Mixamo 要用户的 Adobe 账号；也可以用 Blender 的 Rigify 或手动绑 |
| 背面短裤中间多出一个小尾巴凸起（真尾巴在右后方） | 小 | 删掉多出来的那块 |
| 侧面：耳朵贴图被投影在头侧面，脸颊上还有一条像嘴的轮廓线；后脑有两个圆形凸起 | 64px 下基本看不出 | 可以不修 |
| 贴图上画了深色线稿 | 64px 下看不出 | 不用处理 |
| **64px 下眉毛和眼睛几乎消失** | 影响辨识度 | 贴图里把眉毛加粗、眼睛加深，或者渲染后单独覆盖脸部 |
| **64px 下手臂和身体同色，没有内部线条，手臂分不出来** | 影响可读性 | 卡通阴影加强；加一层由深度或法线算出的内部轮廓线，用描边色 #281B21 |

像素测试：站高正好 64px；颜色全部吸附到 17 色以后，一眼就能认出是牛来（黄身体、粉耳朵、奶油色鼻头、棕短裤、尾巴）。待机站直、不拿剑时轮廓偏窄，属于正常；拿剑、套上动作之后再对比。
