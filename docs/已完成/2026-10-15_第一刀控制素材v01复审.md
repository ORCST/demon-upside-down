# 2026-10-15：第一刀控制素材 v01 复审（Devin）

审查对象：Codex 的 [第一刀控制素材准备 v01](2026-10-15_第一刀控制素材准备v01.md)，即 `art_source/control/heavy_combo_v01/`。只做复审，没有改动素材，也没有启动 ComfyUI。

## 看了什么

`README.md`、`frame0_alignment.png`、`anchor_alignment.png`、`control_contact_sheet.png`。

## 结论：通过

| 项 | 结论 |
| --- | --- |
| 技术做法 | 认可：两版共用一个深度区间，刚体剑尺寸固定，接地修正有逐帧记录，R008 的剑遮挡如实保留 |
| 比例代理 | 大头短身效果明显，保留和原比例对比 |
| 首帧剑角和握点 | **不需要起始过渡**。游戏从 K1（约 R003）开始取帧；R000→R003 剑本来就要转到竖直，差异会被吸收。第一轮验收检查 R000–R004 有没有融化，有的话再做 Blender 起始过渡 |
| 握点水平差 | 牛来双手约在 x=390，白模约 325（768 画布），差 60–70px。原因是牛来肚子前凸。生成结果里牛来的手可能缩进肚子，或者手臂被拉长，**第一轮必须专门检查**。可选：代理 v02 加厚腹部，把手和剑前移约 60px |
| 帧数 | 改用 **R000–R038 共 39 帧原速**，对齐 17k+5，不补帧、不改速；后半段同时测试没有锚点时的表现 |
| 锚点 | 第一轮只放 K4@R008、K6@R012。39 帧只有 12 个潜帧，K2@R005 和 K4 太近，可能冲突 |
